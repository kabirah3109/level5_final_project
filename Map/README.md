Contacts Manager (Map Project)

A lightweight contacts manager web app with a responsive UI. Add, edit, delete and search contacts,data is stored locally in the browser using `localStorage`.

Features
- Add and edit contacts (name + phone number).
- Delete contacts with confirmation.
- Search/filter contacts by name or phone.
- Responsive layout (desktop + mobile).
- Notifications for success, error and warnings.

Files
- [index.html](index.html) — main UI and markup.
- [script.js](script.js) — application logic (add/edit/delete/search, localStorage).
- [style.css](style.css) — styles and responsive rules.
