
# Stack (FIFO only)

A simple web project demonstrating a FIFO queue with a simple UI.

 Overview

This project implements a FIFO (first-in, first-out) queue for actions. `Undo` and `Redo` follow queue semantics: the oldest action is removed first (front-first). The UI shows the queue front first.

Files

- [index.html](index.html): App UI and layout.
- [style.css](style.css): Styles for the UI.
- [script.js](script.js): Queue logic (FIFO) and DOM interactions.
